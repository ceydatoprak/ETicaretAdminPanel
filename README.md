# ETicaretAdminPanel

C# WinForms ve SQL Server kullanılarak geliştirilmiş erken dönem e-ticaret admin paneli projesidir.

Bu proje, C# ve veritabanı işlemlerini öğrenme sürecimde geliştirdiğim ilk projelerden biridir. Temel CRUD işlemleri ve SQL Server bağlantısı üzerine pratik yapmak amacıyla hazırlanmıştır.

## Özellikler

- Admin giriş sistemi
- Ürün listeleme
- Ürün ekleme, güncelleme ve silme
- Kategori ekleme, güncelleme ve silme
- İletişim formu
- Mesajların veritabanına kaydedilmesi
- SQL Server ile veri yönetimi

## Kullanılan Teknolojiler

- C#
- Windows Forms
- SQL Server
- ADO.NET
- Visual Studio

## Not

Bu proje, C# ve veritabanı işlemlerini öğrenme sürecimde geliştirdiğim ilk projelerden biridir.
